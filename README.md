# 🎓 Python Online Examination Portal

A desktop-based Online Examination Portal developed using Python and Tkinter.

## 🚀 Features
- Student Dashboard
- Python Programming MCQ Test
- 10-Minute Examination Timer
- Interactive Question Navigation
- Bookmark Questions
- Automatic Exam Submission
- Result Calculation
- Performance Summary

## 🛠️ Technologies Used
- Python
- Tkinter
- Time Module

## ▶️ How to Run

1. Install Python on your computer.
2. Download or clone this repository.
3. Open the project folder in VS Code.
4. Run the following command:

```bash
python exam_portal.py
```
